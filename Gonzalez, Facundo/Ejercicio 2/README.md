# Ejercicio 2 - Tareas

## ¿De qué trata?
En este ejercicio se desarrolló una API con ExpressJS para administrar tareas.

Cada tarea tiene:
- Un ID.
- Un nombre.
- Un estado que indica si está completada o pendiente.
Los datos se guardan en una base de datos MySQL.

## Tecnologías utilizadas
- Node.js
- ExpressJS
- MySQL
- mysql2
- express-validator
- dotenv
