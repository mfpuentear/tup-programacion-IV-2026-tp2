# Ejercicio 3 - API de Calificaciones
Este ejercicio consiste en desarrollar una API con ExpressJS para administrar las calificaciones de alumnos en distintas materias.
La información se guarda en una base de datos MySQL.

## Tecnologías utilizadas
- Node.js
- ExpressJS
- MySQL
- mysql2
- express-validator
- dotenv
