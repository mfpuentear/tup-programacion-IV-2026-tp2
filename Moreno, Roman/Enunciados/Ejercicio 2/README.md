# API REST - Gestión de Tareas

API backend desarrollada con **Node.js**, **Express.js** y **MySQL** para administrar una lista de tareas personales o laborales. Cuenta con persistencia relacional, validaciones estrictas mediante `express-validator`, control de unicidad por nombres y filtrado avanzado por estado.

## Tecnologías Utilizadas

* **Node.js** - Entorno de ejecución para JavaScript.
* **Express.js** - Framework web para Node.js.
* **MySQL (mysql2)** - Base de datos relacional y cliente de conexión.
* **Express-Validator** - Librería para la validación de parámetros, consultas y cuerpos de solicitudes.
* **Dotenv** - Manejo de variables de entorno.
* **Nodemon** - Herramienta de desarrollo para reinicio automático.
