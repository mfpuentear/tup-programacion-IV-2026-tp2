# API de Gestión de Tareas (ExpressJS & MySQL)

API REST desarrollada con Node.js, ExpressJS y MySQL para administrar una lista de tareas, implementando validaciones robustas y control de unicidad.

## Requisitos Previos
- Node.js instalado.
- Servidor MySQL activo (puerto 3306).

## Instalación y Configuración
